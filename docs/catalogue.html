Build the data catalogue

Catalogue entries come from data already recorded by Depot. Add or update a reviewed registry manifest and publish a release; there is no separate list of entries to maintain in Python.

Important Prerequisite

Use the configured registry and the publication receipts retained in its state root. A release must pass fetch, validation, and verified publication before it can appear in catalogue tables. Catalogue and Manual pages share the existing notebooks/_quarto.yml; rendering does not execute catalogue commands.

Quickstart

Complete the README setup and registration walkthrough first. A registry entry alone does not add a catalogue row: the release must pass fetch → validate → push using the same installation configuration. If no release has been published yet, follow the real-data workflow before running the commands below.

After a successful verified push, run from the Depot checkout:

export DEPOT_CONFIG="$PWD/depot.toml"
uv run --locked depot --config "$DEPOT_CONFIG" catalog build
scripts/render-isolated --profile authoring

Use the reviewed configuration with website = "notebooks". The existing notebooks/_quarto.yml combines the data catalogue and Operator Manual in one Quarto project. Open docs/index.html to browse datasets; use its navbar to open the Operator Manual at docs/overview.html. No second Quarto project is needed.

catalog build reads registry metadata and verified receipts into a pandas DataFrame, builds Great Tables, and writes index.qmd and datasets/ID.qmd under website. Quarto renders those pages. Follow a dataset link to see its resource table and retrieval instructions. Both steps can be repeated without publishing again; there is no Python list of entries to edit.

For routine updates across all registered datasets, use uv run --locked depot --config "$DEPOT_CONFIG" sync, then run the same render helper. Sync performs fetch, validation, publication, retrieval verification, and catalogue generation. To process a selected release, use the operator quickstart.

An empty catalogue means there are no visible entries with eligible verified receipts for their configured destinations. Check publication success, catalogue.visible, the selected configuration, and the destination.

Read → select → tabulate

Stage Existing data Result
Read Registry YAML and successful publication receipts One latest verified release per visible dataset
Select Explicit public fields in PUBLIC_COLUMNS A pandas DataFrame with one row per dataset
Tabulate Catalogue columns and resource summaries Great Tables for the index and dataset pages
Write Rendered Great Tables and page text index.qmd and datasets/ID.qmd

Registry fields supply the title, description, visibility, and audience. Receipts supply the verified layer, version, publication time, commit, provenance, and resource summaries. Failed or unverified attempts cannot add a row; a later failed release leaves the previous verified release listed. Private paths and operational errors are excluded by the public column projection.

For exploration, use the same DataFrame and table functions as the build:

from pathlib import Path

from depot.catalog import catalogue_data, catalogue_table
from depot.config import Config

config = Config.load(Path("/path/to/depot.toml"))
entries = catalogue_data(config)
entries.loc[:, ["id", "title", "version", "published"]]
catalogue_table(entries)

The final expression displays a Great Tables table in a notebook. catalogue_table() selects and labels columns; the library constructs the table markup. Resource tables are built directly from the resource records in each receipt. Fixed table IDs keep repeated builds reproducible.

Dataset metadata and resource records are ordinary pandas DataFrames rendered with Great Tables, just like the catalogue index. Python writes the rendered tables and minimal retrieval instructions into Quarto pages; there are no page template files or template engine. Change CATALOGUE_LABELS to select displayed catalogue columns and registry YAML to update dataset descriptions. Metadata remains literal text in the tables. Great Tables’ HTML is placed in Quarto raw HTML blocks so Markdown-like cell values are not interpreted as page markup.

Implementation

This manual emits catalog.py; edit the block below and explicitly re-emit it. The selection policy is kept separate from DataFrame preparation and presentation. Ordinary website rendering does not execute these examples.

Tip Procedure 
"""Public catalogue data frames and Great Tables, built from verified receipts."""

from html import escape
from pathlib import Path

from great_tables import GT
import pandas as pd

from .config import Config, load_manifest
from .errors import DepotError
from .service import Depot, version_key
from .storage import dataset_lock, read_json, write_json

NOTICE = "Prospects can change between versions. Refined releases follow a stricter schedule."

# An explicit projection prevents internal receipt fields from reaching the website.
PUBLIC_COLUMNS = {
    "id": "id",
    "title": "title",
    "description": "description",
    "layer": "layer",
    "audience": "audience",
    "receipt.version": "version",
    "receipt.timestamp": "published",
    "receipt.commit": "commit",
    "receipt.display.prospector": "prospector",
    "receipt.display.package_name": "package_name",
    "receipt.display.resources": "resources",
    "receipt.access.mode": "access_mode",
    "receipt.access.populated": "populated",
}
CATALOGUE_LABELS = {
    "id": "Dataset",
    "title": "Title",
    "layer": "Layer",
    "version": "Latest verified version",
    "description": "Description",
    "published": "Last published",
}


def text(value: object) -> str:
    # Quarto shortcodes use braces; encode them as well as HTML metacharacters.
    return escape(str(value), quote=True).replace("{", "&#123;").replace("}", "&#125;")


def public_entries(config: Config) -> list[dict]:
    depot = Depot(config)
    entries = []
    for path in sorted(config.registry.glob("*.yaml")):
        try:
            manifest = load_manifest(config, path.stem)
        except DepotError:
            # A broken current policy cannot authorize public visibility.
            continue
        if not manifest["catalogue"]["visible"]:
            continue
        target = str(config.targets[manifest["destination"]["target"]].root / manifest["id"])
        successes = [
            r
            for r in depot.receipts(manifest["id"])
            if r.get("status") == "success"
            and r.get("verified") is True
            and r.get("validation", {}).get("valid") is True
            and r.get("target") == target
        ]
        if not successes:
            continue
        receipt = max(successes, key=lambda r: (version_key(r["version"]), r["timestamp"]))
        entries.append(
            {
                "id": manifest["id"],
                "title": manifest["title"],
                "description": manifest["description"],
                "layer": receipt["display"]["layer"],
                "audience": manifest["catalogue"]["audience"],
                "receipt": receipt,
            }
        )
    return entries


def catalogue_data(config: Config) -> pd.DataFrame:
    """Load one public row per dataset; retain a stable schema when there are none."""
    return (
        pd.json_normalize(public_entries(config))
        .reindex(columns=list(PUBLIC_COLUMNS))
        .rename(columns=PUBLIC_COLUMNS)
        .assign(published=lambda df: df["published"].astype("string").str.split("T").str[0])
        .sort_values("id", ignore_index=True)
    )


def catalogue_table(data: pd.DataFrame) -> GT:
    """Describe the display declaratively; Great Tables owns the HTML markup."""
    return (
        GT(data.loc[:, list(CATALOGUE_LABELS)], id="depot-catalogue")
        .cols_label(**CATALOGUE_LABELS)
        .fmt(columns=list(CATALOGUE_LABELS), fns=text)
        .fmt(columns="id", fns=lambda value: f'<a href="datasets/{value}.html">{text(value)}</a>')
        .cols_align(align="left")
        .tab_options(table_width="100%")
    )


def resources_table(resources: list[dict], dataset_id: str) -> GT:
    data = pd.DataFrame.from_records(resources, columns=["name", "files", "bytes"])
    return (
        GT(data, id=f"depot-resources-{dataset_id}")
        .cols_label(name="Resource", files="Files", bytes="Bytes")
        .fmt(columns="name", fns=text)
        .fmt_integer(columns=["files", "bytes"])
        .tab_options(table_width="100%")
    )


def _write(path: Path, content: str) -> None:
    from tempfile import NamedTemporaryFile

    path.parent.mkdir(parents=True, exist_ok=True)
    with NamedTemporaryFile(mode="w", dir=path.parent, delete=False) as stream:
        stream.write(content)
        temporary = Path(stream.name)
    temporary.replace(path)


def build(config: Config) -> list[dict]:
    with dataset_lock(config.state / "catalogue.lock"):
        data = catalogue_data(config)
        pages = []
        for row in data.to_dict(orient="records"):
            dataset_id = row["id"]
            version = row["version"]
            # Operators supply the private store; the receipt pins the public commit.
            store_variable = "${DEPOT_STORE}"
            commands = (
                f'datalad clone "ria+file://{store_variable}#~{dataset_id}" {dataset_id}\n'
                f"cd {dataset_id}\n"
                f"git checkout --detach {row['commit']}\n"
                f"datalad get releases/{version}"
            )
            direct_access = ""
            if row.get("access_mode") == "unlocked" and row.get("populated") is True:
                relative = f"{row['layer']}/{dataset_id}.data/releases/{version}/"
                direct_access = (
                    "## Use the data directly\n\n"
                    "The lab's Goldmine contains populated, ordinary writable files at "
                    f"`{relative}` relative to its root. Open these files with Python, R, "
                    "or your usual tools; no DataLad commands are required. "
                    "Ask the lab operator for the Goldmine root if needed. "
                    "Work on a personal copy when making changes to a shared release.\n\n"
                )
            details = pd.DataFrame(
                {"Field": label, "Value": row[field]}
                for field, label in {
                    "id": "Dataset",
                    "title": "Title",
                    "description": "Description",
                    "layer": "Layer",
                    "version": "Version",
                    "published": "Published",
                    "commit": "Commit",
                    "prospector": "Prospector",
                    "package_name": "Package",
                    "audience": "Intended audience/use",
                }.items()
            )
            metadata_table = GT(details, id=f"depot-metadata-{dataset_id}").fmt(
                columns="Value", fns=text
            )
            page = (
                '---\ntitle: "Dataset details"\nsidebar: false\n---\n\n```{=html}\n'
                + metadata_table.as_raw_html()
                + "\n```\n\nStatus: validated, published, and verified by fresh retrieval.\n\n"
                + "## Resources\n\n```{=html}\n"
                + resources_table(row["resources"], dataset_id).as_raw_html()
                + "\n```\n\n"
                + direct_access
                + "## Retrieve the archived version with DataLad\n\n"
                + "Set `DEPOT_STORE` to the dataset's RIA store path supplied by the lab operator. "
                + "Use these commands to retrieve the pinned release:\n\n"
                + f"<pre><code>{text(commands)}</code></pre>\n\n"
                + f"Package metadata: releases/{version}/datapackage.json.\n\n{NOTICE}\n"
            )
            relative = f"datasets/{dataset_id}.qmd"
            _write(config.website / relative, page)
            pages.append(relative)
        table = (
            "```{=html}\n" + catalogue_table(data).as_raw_html() + "\n```"
            if not data.empty
            else "No verified datasets are available yet."
        )
        index = (
            '---\ntitle: "Depot data catalogue"\nsidebar: false\ntoc: false\n---\n\n'
            + "Browse datasets available through the lab's Goldmine. Select a dataset to see "
            + "its description, version, resources, and retrieval instructions.\n\n"
            + table
            + "\n\n## About this catalogue\n\n"
            + "Entries appear after publication and fresh-retrieval verification. "
            + "Data remain in Goldmine; this site presents metadata and retrieval instructions.\n\n"
            + f"{NOTICE}\n\n"
            + "See the [Operator Manual](overview.qmd) to register and publish a dataset.\n"
        )
        _write(config.website / "index.qmd", index)
        # Delete only files previously generated by Depot, never an uncontrolled scan.
        previous = read_json(config.state / "catalogue-pages.json") or {"pages": []}
        for relative in set(previous["pages"]) - set(pages):
            from .config import contained

            path = contained(config.website / relative, config.website / "datasets")
            path.unlink(missing_ok=True)
        write_json(config.state / "catalogue-pages.json", {"pages": pages})
        return (
            data.loc[:, ["id", "version"]]
            .rename(columns={"id": "dataset_id"})
            .assign(status="catalogued")
            .to_dict(orient="records")
        )
