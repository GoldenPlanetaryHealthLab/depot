Depot operator manual

Depot consumes completed Prospector releases, publishes validated versions through DataLad, and generates a Quarto catalogue from verified publication receipts. Start with the README walkthrough for setup, registration, and the complete real-data workflow. This manual documents the implementation; its code blocks emit the Python modules and do not execute ingestion.

Important Prerequisite

Use Spack-managed Python 3.14, Python packages locked by uv, DataLad, git-annex, Git, and Quarto 1.9 or newer. Configure reviewed source roots and publication targets before running release commands.

Quickstart

Complete software and configuration setup first. The Prospector must already provide VERSION/datapackage.json and local resources; the selected registry must contain a reviewed entry for the dataset. Keep the same configuration for every step. For Kiribati, run from the Depot checkout:

export DEPOT_CONFIG="$PWD/depot.toml"
uv run --locked depot --config "$DEPOT_CONFIG" fetch kiribati-biomarkers v0.2.2
uv run --locked depot --config "$DEPOT_CONFIG" validate kiribati-biomarkers v0.2.2
uv run --locked depot --config "$DEPOT_CONFIG" push kiribati-biomarkers v0.2.2
uv run --locked depot --config "$DEPOT_CONFIG" catalog build
scripts/render-isolated --profile authoring

Point the configuration’s website setting to this checkout’s notebooks/ directory; substitute another dataset ID and version as needed. Fetch must succeed before validate; validate must succeed before push. Expect fetched, validated, success, and catalogued in that order. Push records success only after a fresh clone retrieves and validates the published bytes. Inspect failures with uv run --locked depot --config "$DEPOT_CONFIG" receipts kiribati-biomarkers.

The catalogue and Manual share notebooks/_quarto.yml and one output directory, docs/. Open docs/index.html to browse datasets and docs/overview.html for operating instructions. catalog build updates the landing page and generated dataset pages without changing authored Manual chapters.

For subsequent runs, uv run --locked depot --config "$DEPOT_CONFIG" sync performs fetch, validate, push, and catalogue generation for every registered dataset and discovered version. It has no dataset selector. Use the individual commands to test a small dataset while another dataset is running. Render the unified site afterward. If publication is already verified, start at catalog build; see the catalogue guide.

errors.py

Tip Procedure 
"""Structured errors safe to display without subprocess output or credentials."""


class DepotError(Exception):
    def __init__(self, code: str, message: str, details: dict | None = None):
        super().__init__(message)
        self.code = code
        self.details = details or {}

    def as_dict(self) -> dict:
        return {"code": self.code, "message": str(self), "details": self.details}

storage.py

Tip Procedure 
"""Atomic local records and nonblocking Linux per-dataset locks."""

from contextlib import contextmanager
import fcntl
import json
import os
from pathlib import Path
from tempfile import NamedTemporaryFile

from .errors import DepotError


def read_json(path: Path) -> dict | None:
    try:
        return json.loads(path.read_text())
    except FileNotFoundError:
        return None
    except (OSError, ValueError) as exc:
        raise DepotError(
            "invalid_state", "An operational record is unreadable; inspect internal state."
        ) from exc


def write_json(path: Path, value: dict) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    with NamedTemporaryFile(mode="w", dir=path.parent, delete=False) as stream:
        temporary = Path(stream.name)
        try:
            json.dump(value, stream, sort_keys=True, indent=2)
            stream.write("\n")
            stream.flush()
            os.fsync(stream.fileno())
        except BaseException:
            temporary.unlink(missing_ok=True)
            raise
    try:
        temporary.replace(path)
    finally:
        temporary.unlink(missing_ok=True)


@contextmanager
def dataset_lock(path: Path):
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("a") as stream:
        try:
            fcntl.flock(stream, fcntl.LOCK_EX | fcntl.LOCK_NB)
        except BlockingIOError as exc:
            raise DepotError(
                "dataset_locked", "Another operation holds this dataset's lock; retry later."
            ) from exc
        try:
            yield
        finally:
            fcntl.flock(stream, fcntl.LOCK_UN)
